# 模板平台

| 项目 | 内容 |
| --- | --- |
| 模块定位 | 提供分类发现、固定版本预览、分享者与互动展示、模板包分发和迁移指令生成能力 |
| 对应代码 | `apps/web/`、`apps/preview/`、`packages/catalog/`、`packages/schema/`、`prototype/` 和模板发布流水线 |
| 所属 M 里程碑 | [M1](../roadmap.md#m1) |

| 最近更新时间 | 2026-08-10 |

## 职责与边界

- 展示、搜索、筛选和排序已经发布的模板实现。
- 提供首页 Category 预览、分类总览和单分类结果。
- 展示分享者名称、头像、浏览量和点赞，并为社区投稿保留统一目录条目。
- 管理网站 Light / Dark、中文 / English 偏好和账号能力入口。
- 提供固定版本详情、内嵌预览、独立预览和组件实验室入口。
- 从同一模板记录生成页面、下载信息和 AI 迁移指令。
- 维护固定包、校验值、缓存、SEO、匿名统计和紧急下架入口。
- 不读取用户项目，不远程执行用户项目构建，不提供完整项目脚手架。

## 结构与数据流

```text
app.js 中的原型数据
  -> Category / 分享者 / 浏览量 / 点赞
  -> 首页 / 分类总览 / 单分类页 / 详情弹窗
  -> 主题、语言和能力预留反馈

生产阶段：模板源码与 Manifest
  -> 发布门禁
  -> 固定版本记录与模板包
  -> 模板列表 / 详情 / 预览 / 迁移指令
  -> 用户交给 AI 在本地迁移
```

## 关键决策

- 平台、框架、组件库和模板组成四段式 ID。
- 页面、预览、模板包和迁移指令绑定同一固定版本。
- 预览使用独立来源或严格 sandbox，网络访问采用白名单。
- `withdrawn` 从公开入口移除，固定页保留最小事故记录。
- 生产技术栈、版本基线、构建和部署边界以 [技术架构与构建](./技术架构与构建.md) 为准。
- 主站使用 Next.js App Router，独立预览使用 Vite MPA；二者分别部署为 Vercel Project。
- 原型继续使用无构建的静态 HTML、CSS 和 JavaScript，方便直接检查设计并作为生产迁移基准。
- 原型模板数据直接维护在 `prototype/app.js`，方便快速调整设计和交互。
- 模板产物与目录条目分开建模，分类、分享者和热度变化不会污染固定模板版本。
- 账号、投稿和持久化点赞由能力开关控制；关闭时保留导航、路由与数据契约。
- 网站主题独立于模板主题，网站切换 Dark 不代表 `quiet-grid` 支持 Dark 模板实现。

## 当前实现

可直接打开的交互原型已经覆盖：

- 模板搜索、排序、Category 导航与总览、单分类结果和空状态。
- 分享者身份、浏览量、心形点赞和模板详情弹窗。
- 网站明暗主题、中英文切换，以及登录、注册、投稿和 AI 使用入口的预留反馈。
- 桌面三列、移动单列和移动端横向分类浏览。
- `prototype/browser-smoke.cjs` 使用本机 Edge 验证主要交互与 390px 无横向溢出。

`@uidevtpl/catalog` 已把目录条目、Category、分享者、指标、Showcase、组件清单和迁移指令字段收口为版本化开发 fixture。`apps/web` 已实现首页、模板库、分类总览、单分类、最新/固定版本详情、使用说明和登录/注册/投稿预留路由；搜索、筛选、排序、主题偏好、语言偏好、本地点赞和迁移指令复制入口已经接通，分类筛选与详情 Showcase 选择会保留在 URL 中。主站已部署到 `uidevtpl.chaosyn.com`，但当前条目的 `availability` 仍是 `draft`；下载地址、SHA-256、真实固定预览产物、持久化互动、匿名统计、SEO 和完整双 Project 发布链路仍不能代表生产能力。`apps/preview` 已能按固定预览深链解析 Showcase/组件实验室入口，并提供 Vercel MPA 重写配置。

## 验证方式

- 运行格式化、静态分析、类型检查、单元测试和生产构建。
- `packages/catalog/src/index.test.ts` 覆盖目录筛选、固定版本路由、Showcase 固定预览路径和迁移指令身份绑定。
- 主站与预览站分别通过 TypeScript 检查和生产构建；完整模板门禁继续由首个模板模块单独推进。
- 验证固定 URL、缓存、SHA-256、下载失败和紧急下架流程。
- 在规定浏览器与视口检查预览隔离、交互、无障碍和 Core Web Vitals。
- 验证匿名统计不包含用户业务需求和项目数据。
- 当前原型运行 `npm run verify`，并检查 `prototype/references/` 中的桌面与手机参考截图。
