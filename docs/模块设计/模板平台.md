| 项目 | 内容 |

## 职责与边界

- 展示、搜索、筛选和排序已经发布的模板实现。
- 提供首页 Category 预览、分类总览和单分类结果。
- 展示分享者名称、头像、浏览量和点赞，并为社区投稿保留统一目录条目。
- 管理网站 Light / Dark、中文 / English 偏好和账号能力入口。
- 提供固定版本详情、内嵌预览、独立预览和组件实验室入口。
- 从同一模板记录生成页面、下载信息和 AI 迁移指令。
- 维护固定包、校验值、缓存、SEO、匿名统计和紧急下架入口。
- 不读取用户项目，不远程执行用户项目构建，不提供完整项目脚手架。

## 结构与数据流

```text
app.js 中的原型数据
  -> Category / 分享者 / 浏览量 / 点赞
  -> 首页 / 分类总览 / 单分类页 / 详情弹窗
  -> 主题、语言和能力预留反馈

生产阶段：模板源码与 Manifest
  -> 发布门禁
  -> 固定版本记录与模板包
  -> 模板列表 / 详情 / 预览 / 迁移指令
  -> 用户交给 AI 在本地迁移
```

## 关键决策

- 平台、框架、组件库和模板组成四段式 ID。
- V1 公开 React 模板统一使用 `shadcn` 作为 `library` 段；长期继续保留该维度，为其他组件体系提供独立实现。
- 页面、预览、模板包和迁移指令绑定同一固定版本。
- 预览使用独立来源或严格 sandbox，网络访问采用白名单。
- `withdrawn` 从公开入口移除，固定页保留最小事故记录。
- 生产技术栈、版本基线、构建和部署边界以 [技术架构与构建](./技术架构与构建.md) 为准。
- 主站使用 Next.js App Router，独立预览使用 Vite MPA；二者分别部署为 Vercel Project。
- 官网使用站点自有 shadcn/ui 组件源码；模板分别拥有自己的 shadcn/ui 源码，双方不共享运行时 UI 包。
- 原型继续使用无构建的静态 HTML、CSS 和 JavaScript，方便直接检查设计并作为生产迁移基准。
- 原型模板数据直接维护在 `prototype/app.js`，方便快速调整设计和交互。
- 模板产物与目录条目分开建模，分类、分享者和热度变化不会污染固定模板版本。
- 账号、投稿和持久化点赞由能力开关控制；关闭时保留导航、路由与数据契约。
- 网站主题独立于模板主题，网站切换 Dark 不代表 `quiet-grid` 支持 Dark 模板实现。

## 视觉基线

- [原型首页](../../prototype/index.html) 是主站的视觉和信息架构基准，生产页面应保持相同的浏览顺序：居中 Hero 搜索、分类拼贴、精选模板和全部模板。
- 主站采用中性白底、细边框、克制阴影和黑色文字，主导航将“模板”放在页面中间，右侧保留分享、语言、主题、登录和注册入口。
- 分类卡片使用四块代表性视觉拼贴；模板卡片使用 `TemplateVisual` 渲染 `Quiet Grid` 或 `Signal Canvas` 预览，避免把真实模板页面压缩成普通图片卡片。
- 详情页使用返回模板库、状态与版本徽章、兼容信息条和内嵌预览工作台的结构；品牌、文案、Catalog 数据和固定路由仍归 UIDevTpl 所有。
- v0 Templates 只作为布局和浏览逻辑参考，主站不复制其品牌标识、页面文案或模板内容。
- shadcn/ui 提供官网的组件源码、交互基础和主题变量入口，UIDevTpl 的品牌、构图、字体、密度与内容层级继续由本站视觉基线决定。

## 当前实现

可直接打开的交互原型已经覆盖：

- 模板搜索、排序、Category 导航与总览、单分类结果和空状态。
- 分享者身份、浏览量、心形点赞和模板详情弹窗。
- 网站明暗主题、中英文切换，以及登录、注册、投稿和 AI 使用入口的预留反馈。
- 桌面三列、移动单列和移动端横向分类浏览。
- `prototype/browser-smoke.cjs` 使用本机 Edge 验证主要交互与 390px 无横向溢出。

`@uidevtpl/catalog` 已把目录条目、Category、分享者、指标、Showcase、组件清单和迁移指令字段收口为版本化开发 fixture。`apps/web` 已实现首页、模板库、分类总览、单分类、最新/固定版本详情、使用说明和登录/注册/投稿预留路由；搜索、筛选、排序、主题偏好、语言偏好、本地点赞和迁移指令复制入口已经接通，分类筛选与详情 Showcase 选择会保留在 URL 中。生产主站的共享导航、首页、分类卡片、模板预览卡片和详情页已经按原型视觉基线重构，数据与路由契约保持不变，但站点自有 shadcn/ui 组件层尚未创建。主站已部署到 `uidevtpl.chaosyn.com`，当前 Catalog 仍使用 `web/react/heroui/quiet-grid` 草稿身份，条目的 `availability` 仍是 `draft`。这套模板源码、Catalog 条目和预览数据将在重写开始时删除，再以 `web/react/shadcn/quiet-grid` 创建全新实现。下载地址、SHA-256、固定发布产物、Registry Item、持久化互动、匿名统计、SEO 和完整双 Project 发布链路仍不能代表公开生产能力。`apps/preview` 已部署到独立域名 `preview.chaosyn.com`，能按固定预览深链解析 Showcase/组件实验室入口，并提供 Vercel MPA 重写配置；主站生产详情页 iframe 已接入该域名，预览深链和 iframe 展示已经通过线上验收。当前 HeroUI 预览属于待删除草稿，不约束新模板的设计与验收。

## 验证方式

- 运行格式化、静态分析、类型检查、单元测试和生产构建。
- `packages/catalog/src/index.test.ts` 覆盖目录筛选、固定版本路由、Showcase 固定预览路径和迁移指令身份绑定。
- 主站与预览站分别通过 TypeScript 检查和生产构建；完整模板门禁继续由首个模板模块单独推进。
- 验证官网与模板没有共享运行时 UI 包，`library=shadcn` 的目录、路由、预览、ZIP 和 Registry Item 使用同一固定身份。
- 验证固定 URL、缓存、SHA-256、下载失败和紧急下架流程。
- 在规定浏览器与视口检查预览隔离、交互、无障碍和 Core Web Vitals。
- 验证匿名统计不包含用户业务需求和项目数据。
- 当前原型运行 `npm run verify`，并检查 `prototype/references/` 中的桌面与手机参考截图。
