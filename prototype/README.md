# UIDevTpl 高保真原型

本目录是 UIDevTpl 的可交互设计原型，对应 [M1 模板平台](../docs/roadmap.md#m1)。它用于确认模板发现、分类浏览和社区信息结构，不代表生产网站已经完成。

## 直接查看

双击打开 [`index.html`](./index.html) 即可，不需要启动开发服务器。

原型运行时保持简单：

- `index.html`：页面结构。
- `styles.css`：视觉与响应式布局。
- `app.js`：模板数据和交互。

本地图片位于 `assets/`，图标脚本位于 `vendor/`。

## 当前覆盖

- v0 Templates 风格的模板发现首页。
- Category 下拉菜单、分类总览和单分类页面。
- 模板作者头像与名称、浏览量、心形点赞。
- 明暗主题和中英文切换。
- 登录、注册、分享模板、AI 使用的预留反馈。
- 模板详情弹窗。
- 桌面三列、移动单列和移动端横向分类浏览。

## 验证

```powershell
npm run verify
```

冒烟测试通过本机 Edge 直接打开 `file://` 页面，不会启动开发服务器。
