# UIDevTpl 主站布局原型

这是 UIDevTpl Signal Desk 的低保真 HTML / CSS / JavaScript 原型，用来确认主站的信息层级、页面布局和核心功能位置。它不追求最终视觉细节，正式站会把这些位置替换为 Next.js + shadcn/ui 组件。

## 打开方式

直接打开 `index.html` 即可。原型不依赖开发服务器，也不依赖外部网络资源。

## 已覆盖的功能点

- 首页发现工作台：搜索、精选系统、用途索引、最新系统和迁移流程。
- 模板库：关键词、用途、实现方式和排序筛选。
- 用途目录：进入用途后回到模板库结果。
- 系统详情抽屉：Showcase、组件、Tokens、迁移四个页签。
- 预览视口：桌面、平板、手机。
- 复制迁移指令、点赞、主题切换和中英文切换。
- 移动端菜单、筛选面板和 390px 无横向溢出。

预览板使用线框表达页面层级，不代表最终模板视觉。正式实现会连接真实 Preview Project 和固定版本 Catalog。
