# 第二视觉家族

| 项目 | 内容 |
| --- | --- |
| 模块定位 | 为公开 V1 提供与 Quiet Grid 明显不同的第二套完整视觉选择 |
| 对应代码 | 待命名的家族目录与 `packages/templates/web/` 下的实现目录 |
| 所属 M 里程碑 | [M3](../roadmap.md#m3) |
| 当前状态 | 未开始 |
| 最近更新时间 | 2026-08-10 |

## 职责与边界

- 定义独立的颜色、字体、密度、形状、构图和内容规则。
- 使用真实源码提供组件实验室、两个 Showcase 和三类页面骨架。
- 证明模板库提供真实的风格选择，禁止依靠 Quiet Grid 浅层换色交付。
- V1 只要求一个完整 Web 实现，具体框架和组件库在设计启动前锁定。

## 结构与数据流

```text
第二家族视觉方向
  -> 家族契约与资产规则
  -> Web 模板实现
  -> 预览与固定模板包
  -> 独立发布门禁
```

## 关键决策

- 第二家族必须与 Quiet Grid 在密度、形状、字体、色彩和主要构图上形成清楚差异。
- 仍然遵循 V1 核心组件、固定版本、MIT 代码授权和迁移门禁。
- 不能借用 Quiet Grid 的预览图或用自动换色结果替代独立实现。

## 当前实现

尚未确定家族 ID、视觉方向、组件库和 Showcase 题材。

## 验证方式

- 独立通过模板规范中的全部自动门禁与人工视觉门禁。
- 与 Quiet Grid 并排评审，确认用户能清楚区分两套视觉语言。
- 完成固定模板包、预览一致性和真实项目迁移验证。

## 待扩展项

- 确认家族 ID、设计方向和两个 Showcase 题材。
- 确认框架、组件库和稳定版本范围。
- 公布后根据用户选择与迁移数据决定后续家族方向。
