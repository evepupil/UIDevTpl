# 模板平台

| 项目 | 内容 |
| --- | --- |
| 模块定位 | 提供模板发现、固定版本预览、模板包分发和迁移指令生成能力 |
| 对应代码 | `prototype/index.html`、`prototype/app.js`、`prototype/render.js`、`prototype/lib.js`；计划中的网站应用、模板元数据 Schema、预览构建和发布流水线 |
| 所属 M 里程碑 | [M1](../roadmap.md#m1) |
| 当前状态 | 进行中 |
| 最近更新时间 | 2026-08-10 |

## 职责与边界

- 展示、搜索、筛选和排序已经发布的模板实现。
- 提供固定版本详情、内嵌预览、独立预览和组件实验室入口。
- 从同一模板记录生成页面、下载信息和 AI 迁移指令。
- 维护固定包、校验值、缓存、SEO、匿名统计和紧急下架入口。
- 不读取用户项目，不远程执行用户项目构建，不提供完整项目脚手架。

## 结构与数据流

```text
原型模板记录
  -> 模板库 / 详情 / 视口与 Showcase 控制
  -> 独立 preview.html
  -> 迁移指令与固定包信息

生产阶段：模板源码与 Manifest
  -> 发布门禁
  -> 固定版本记录与模板包
  -> 模板列表 / 详情 / 预览 / 迁移指令
  -> 用户交给 AI 在本地迁移
```

## 关键决策

- 平台、框架、组件库和模板组成四段式 ID。
- 页面、预览、模板包和迁移指令绑定同一固定版本。
- 预览使用独立来源或严格 sandbox，网络访问采用白名单。
- `withdrawn` 从公开入口移除，固定页保留最小事故记录。
- 原型使用无构建的静态 HTML、CSS 和 JavaScript，方便直接检查设计；该选择不锁定生产网站技术栈。
- 原型模板卡片、详情、预览和迁移文本统一读取 `prototype/data.js`，先验证单一数据源原则。

## 当前实现

已完成可直接打开的高保真交互原型：

- 模板库支持搜索、框架和视觉气质筛选、排序、URL 状态和空结果。
- 模板详情支持固定身份信息、Showcase 切换、四种视口、独立预览、组件实验室和固定包摘要。
- “复制给 AI”由固定模板记录生成，剪贴板不可用时提供手动复制回退。
- `prototype/preview.html` 使用单独文档运行真实交互 Showcase，支持重置和响应式布局。
- `prototype/browser-smoke.cjs` 使用本机 Edge 验证桌面主流程与 390px 无横向溢出。

生产网站、模板 Schema、固定产物、缓存、匿名统计、SEO 和 Cloudflare 部署尚未实现。原型中的版本、下载域名和 SHA-256 均为明确标记的演示数据。

## 验证方式

- 运行格式化、静态分析、类型检查、单元测试和生产构建。
- 验证固定 URL、缓存、SHA-256、下载失败和紧急下架流程。
- 在规定浏览器与视口检查预览隔离、交互、无障碍和 Core Web Vitals。
- 验证匿名统计不包含用户业务需求和项目数据。
- 当前原型运行 `npm run verify`，并检查 `prototype/references/` 中的桌面与手机参考截图。
